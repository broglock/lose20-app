# Lose20

Weight-loss coaching app (installable web app) served by GitHub Pages at https://broglock.github.io/lose20-app/

- Meal photos analyzed by Claude, weight and gym tracking, charts, and Maya the coach avatar.
- `windows/` holds the Windows check-in script, which updates itself from this site using the hashes in `version.json`.

This repo holds code only. Data syncs to a separate private repo, and API keys stay on each device. Releases are made with `release.py` in the full project folder.
